# Role Navigation Guide V2.60

## Available Roles

### 🦺 Volunteer (อาสาสมัคร)
**Access:** HOME, PEOPLE, CARE, HELP
- Dashboard → My tasks for the day
- People › Citizens → Look up citizens
- Care › Home Visits → Record visits
- Care › Assessments → Health measurements
- Care › Early Warning → Check alerts
- Care › Referrals → Send referrals

### 👤 Viewer (ผู้ดู)
**Access:** HOME, PEOPLE, INSIGHTS, HELP
- Read-only access to population and analytics data
- Cannot create or edit records

### 🏢 District Admin (ผู้ดูแลอำเภอ)
**Access:** HOME, PEOPLE, CARE, SERVICES, MAPS, INSIGHTS, AI, HELP
- Full operational access for district
- Can manage citizens, visits, referrals
- Access to analytics and GIS

### 🏛️ Province Admin (ผู้ดูแลจังหวัด)
**Access:** All groups including ADMIN
- Province-wide oversight
- System administration access

### 🔑 Super Admin (ผู้ดูแลระบบ)
**Access:** All groups, all pages
- Complete platform control
