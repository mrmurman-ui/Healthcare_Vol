# Thai Fonts for PDF Export

Place Thai font files in this folder to enable Thai text in PDF exports.

## Recommended Fonts

### Option 1: TH Sarabun New (แนะนำ)
1. Download from: https://www.f0nt.com/release/th-sarabun-new/
2. Copy these files to this folder:
   - `THSarabunNew.ttf`
   - `THSarabunNew Bold.ttf`

### Option 2: Noto Sans Thai
1. Download from: https://fonts.google.com/noto/specimen/Noto+Sans+Thai
2. Copy these files to this folder:
   - `NotoSansThai-Regular.ttf`
   - `NotoSansThai-Bold.ttf`

### Option 3: Windows Auto-detect
If you have Microsoft Office or Thai language pack installed, fonts are already
at C:\Windows\Fonts\THSarabunNew.ttf and will be found automatically.

## After Installing
Restart the application — PDF export will automatically use the Thai font.
If no font is found, the system exports an HTML file instead (fully readable Thai).
